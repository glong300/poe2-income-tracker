# POE2 每日通货收益

面向《流放之路 2》的 Windows 本地账本工具。它用手动快照和收支调整记录每日通货变化，区分国服与国际服经济数据。

## 当前能力

- 新资料默认国服；可切换国际服，两个区服的快照、调整和价格不会混算。
- 手动快照、交易/兑换/制作收支调整、按日与按周账本。
- 手动价格快照与 CSV 导入；同一时点的手动确认价优先于自动价。
- 国际服行情状态预留 poe.ninja 适配器；国服在验证数据源前明确显示“未配置”。
- 本地候选审核：截图/OCR 或日志接入只能生成候选；用户可以修改数量后确认入账，或直接丢弃。

## 使用流程

1. 首次启动默认使用国服；右上角可切换国际服。切换后，快照、收支、价格和历史都会立即按区服隔离。
2. 在“今日账本”连续保存两次余额快照，即可看到净变化；如有交易、兑换或制作消耗，使用“记录收支调整”补充原因。
3. 在“收益历史”按某天或以该日期为起点的一周查看同区服账本。
4. 在“价格管理”粘贴 CSV 并导入，确认价只会保存到当前区服，且优先于相同时间点的自动价格。
5. 若未来 OCR/日志适配器写入本地候选，必须通过候选卡片的“确认入账”才会创建有效快照；它不会自动入账。

## 自动行情边界

当前版本只提供国际服 poe.ninja 与国服市场的独立适配器边界和状态展示，**不会在客户端直接抓取第三方行情**。这是为了保持本地账本稳定并避免把未验证的第三方接口、代理或凭据写入桌面端。手动 CSV 价格不受此限制，可离线使用。

## 本地运行

```bash
pnpm install
pnpm tauri dev
```

测试与构建：

```bash
pnpm exec vitest run
cargo test --manifest-path src-tauri/Cargo.toml
pnpm tauri build
```

在 macOS 上，构建配置只生成 `.app` 以便本地验证；Windows 主机仍使用基础配置生成 Windows 安装包。

## 手动价格 CSV

在当前选择的区服导入，表头必须完全为：

```csv
currency_id,value,quoted_in,captured_at
exalted,12,chaos,2026-09-03T12:00:00+08:00
```

`value` 必须是正整数。导入行会作为手动确认价格保存；不会导入或猜测其它区服的价格。

## 隐私与安全

账本 SQLite 数据库仅保存在本机。应用不读取游戏内存、不注入或自动操作游戏客户端，也不上传快照、候选或账本数据。自动行情失败不会阻断本地记账。
